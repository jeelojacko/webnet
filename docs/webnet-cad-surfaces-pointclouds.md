# WebNet CAD Surfaces and Point Clouds

## Purpose
Keep later-phase surface and point-cloud work aligned with survey-first goals.

## Surface direction
Needed concepts:
- TIN source points
- breaklines
- boundaries/voids
- triangles
- contours
- volume surface relationships

## Point-cloud direction
Primary intended use:
- view already-classified LAS/LAZ/COPC data
- filter/thin/extract
- build surfaces/volumes

Non-goal:
- full classification science suite inside browser

## Browser constraints
- streaming/LOD
- workers for filtering/thinning
- optional helper boundary for heavy workflows
