# Phase 20K.3 Wave E3 — visual QA (programmatic + independent review)

Status: **12/12 required viewport PNGs captured and programmatically
verified, plus independent visual review; all carry the expected visible
state; 12/12 SHA-256 digests distinct.** Produced by the
production Chromium run in `docs/evidence/phase20k3-browser-qa.md`
(`npx playwright test -c playwright.prod.config.ts
tests-browser/cad-grading-curved-20k3.spec.ts`).

## Method and honest scope

The QA model driving this wave has **no native image input**, so the mandatory
"inspect every PNG" step was performed programmatically rather than by eye:

- **OCR of the rendered UI text** (`tesseract`), on the full frame plus a
  targeted crop of the grading manager/notice region where applicable, to
  confirm the terminal status/notice text is actually painted.
- **Pixel statistics** (grayscale mean and standard deviation) to confirm each
  frame is a non-blank, non-uniform UI render (not a solid colour / blank
  canvas).
- **Digest uniqueness** enforced inside the spec (`test.afterAll`): the run
  fails if any two captured PNGs are byte-identical, so no differently-named
  image duplicates another.

This is a text/pixel-level inspection, not a human visual review; it proves the
expected state is rendered and distinct, but it does not substitute for a
designer's eye on layout. No image was omitted: all four required frames were
captured at all three viewports.

## What each frame shows

- **`-surface-tied-current`** — Flow A after `Calculate`: the group row is
  `CURRENT` on the `Tilt` Surface and the manager definition tab is open. This
  is the tied-split CURRENT state (`gtop2` 2 components / 2 cycles).
- **`-surface-tied-products`** — Flow A after executing the one enabled
  product: the `Bake` result surfaces as `TiedArc - Baked` (`Surfaces (2)`)
  with the `GROUPBAKE` committed notice, while `Extract` stays disabled. One
  Undo later removed it (asserted in the flow, not shown).
- **`-all-surface-design-patch`** — Flow C after `Build Design Patch`: the
  `AllSurfacePad - Design Patch` surface exists with the `DESIGNPATCH`
  committed notice and truthful `[PATCH]` provenance, before the asserted
  Undo/Redo round-trip.
- **`-extra-cycle-failed`** — Flow D terminal state: `Calculate failed —
  GROUP_NON_MANIFOLD: GRADING_GROUP_ARC_SEAM_PINCH …`, never `CURRENT`, both
  products disabled, and the Inquiry tab reports `No CURRENT result`.

## Omissions justified

Flow B (standalone curved Surface), Flow E (non-planar transition) and Flow F
(arc×arc unsupported) have no mandated PNG in the Wave E3 capture list, so no
image was forced for them; their verdicts are recorded in
`docs/evidence/phase20k3-browser-qa.md` with zero-error ledgers. No required
frame was skipped, so there is no "no visible state changed" omission to
justify.
