- `src/workers/preanalysisSparseAutoRoute.ts` — sibling route, DISABLED by
  default (`isPreanalysisSparseAutoRouteEnabled()` is false; disabled
  short-circuits to TypeScript with zero WASM init). Static eligibility:
  runMode preanalysis, 2D, no robust/TS-correlation/auto-adjust/cluster
  dual-pass/inline auto-adjust/GPS-covariance, station unknowns <= 128.
  Runtime: pre-dispatch gated wrappers (`PreanalysisGatedCorrectionSolver`
  counting one planning system per native correction entry,
  `PreanalysisGatedCovarianceCapture` pairing each covariance call to a

  plus one bounded deterministic all-pairs verification set per system
  (n^2 <= 16384) through the same native delegate, condition warn-only, no
  correction-oracle authority, pairing coverage required, whole-session
  atomic TypeScript restart from the original immutable request (exactly
  once, never mixed). Reuses `loadSparseAutoRouteBundle` (existing
  adjustment loader/cache, unchanged). Test-only hooks
  (`setPreanalysisSparseAutoRouteTestHooks`: unknownCountOverride,
  systemCapOverride, forceC2Failure, forcePhysicalFailure) exercise
  boundaries without protocol or user-facing-flag changes.
- `src/workers/adjustmentWorker.ts` (dispatch only) — injected runtime
  precedence unchanged; runMode preanalysis dispatches to the new route,
  everything else keeps the existing Phase 7C route. Protocol unchanged.
