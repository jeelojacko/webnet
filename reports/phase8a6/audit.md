# Phase 8A.6 audit (evidence-only covariance sentinel proof, test-only)

Scope: independent bounded dense-selected covariance sentinel from the same
planning system; C1 dense-selected oracle, C2 inverse residual, C3 hybrid;
physical covariance validation; fault injection; production-shaped
whole-session policy with atomic all-or-TS fallback. No production
routing/algorithm changes; production worker unchanged.

## Modules (all TEST/EVIDENCE ONLY, no production imports)

- `src/engine/phase8a6SparseCovarianceSentinel.ts` — packed sparse normal
  accumulator (N = A'WA straight from packed design rows + packed
  upper-triangle weights; no dense P, no full Qxx), deterministic column
  probes with the existing scale/factor/solve primitives
  (`scaleNormalMatrix`, `choleskyDecomposeWithDamping`,
  `solveSPDFromCholesky`), C1/C2/C3 evaluators, physical validation
  (finite, positive diagonal, symmetry, Cauchy-Schwarz), query builders.
  Cap: 128 unknowns, fail-closed (throw / damped).
- `src/engine/phase8a6SentinelFaults.ts` — deterministic fault suite:
  diagonal-x4, off-diagonal-x3, sign flip, query swap, NaN/Infinity
  (expect throw), missing/duplicate query (C1 length gate), packing
  truncation, plus two documented blind spots (transposed symmetric
  queries; sub-tolerance diagonal nudge).
- `src/engine/phase8a6SessionPolicy.ts` — pure session policy evaluator:
  unknown cap 128, planning-system cap 64, static/physical/correction/C3
  gates, atomic whole-session all-or-TS-fallback.
- `scripts/phase8a6CovarianceSentinelBridge.ts` — Phase 8A bridge plus
  selected-covariance capture wrappers (compact per-call metrics) and
  per-system compact sentinel metrics computed in-bridge from the ACTUAL
  captured packed inputs. C1 is a TS packed-decode consistency check
  (both sides TS). C2 is the independent check: the inverse residual
  judged on NATIVE values — the production returned values where they
  cover complete columns, plus a bounded test-only full all-pairs
  verification set through the same raw native delegate. The production
  query plan is the selected plan (station+connected, ~10 queries here),
  which rarely covers a full column; the verification set is invisible to
  production diagnostics and changes no production result. Production
  worker untouched.
- `tests/helpers/phase8a6WorkerEvidence.ts` — single-run + reused-worker
  mixed-session stress helpers (timings recorded only).

## Standing limitations (carried into the readiness report)

- True selected-vs-dense covariance capture inside the production engine
  would be invasive; the sentinel works from captured packed inputs with
  test-only code (C1 oracle is dense, C2 needs no inverse).
- In-bridge C1 uses diagonal queries (packed-decode consistency, both sides
  TS — it cannot judge the native solver). The independent solver check is
  C2-native: production native values where they cover complete columns,
  plus a bounded test-only full all-pairs verification set through the same
  native solver (production diagnostics untouched). A dedicated pure fault
  test proves C2 rejects a corrupted native value.
- Emergent real sessions hit exactly 127/128/129 unknowns (chain-star maps 1:1,
  proven direct-TS); 63/64/65 planning-system counts cannot emerge from
  preanalysis sessions, so that boundary is pure-policy evaluation.
- Internal restart is the existing clean TypeScript rerun (same
  fail-closed shape as Phase 7C/7D); no new production restart hooks.
- Verdict: every evidence criterion passes, yet Phase 8B automatic sparse
  preanalysis routing stays NO-GO — the evidence is test-only by design
  (test-only verification queries, pure-policy system counts, no
  production hooks), so production readiness is not achievable in this
  evidence-only phase.
